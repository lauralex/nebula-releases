# Nebula Free

[Download Nebula Free for Windows](https://github.com/lauralex/nebula-releases/releases/latest/download/NebulaClient.exe)

Run NebulaClient.exe to launch Nebula Free. This launcher automatically checks for signed runtime updates before starting Rocket League. Keep using the same launcher for future runtime updates; no per-release download is needed.

Software updates do not enable research recording or change recording consent. Recording remains a separate, affirmative choice. Older copies without updater code need this launcher once. The launcher executable itself is not self-replaced.

[Release notes and versioned downloads](https://github.com/lauralex/nebula-releases/releases/latest)

This repository contains public distribution files only. It does not contain private source, research recordings, account credentials or signing keys. The component ZIPs are installed automatically by the launcher; users do not need to install them manually.
